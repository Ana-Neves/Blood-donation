# 🩸 Blood Drops - Blood Donation

Management system for blood donation institutions, developed with the goal of optimizing processes, centralizing information, and increasing efficiency in serving donors and patients.

---

## 📌 About the Project

**Blood Drops** is a system based on CRUD (Create, Read, Update, Delete) operations that allows for the complete management of data related to blood donation.

The platform was created to solve common problems faced by institutions, such as:

* Lack of data organization
* Scheduling errors
* Difficulty with internal communication
* Lack of information centralization

---

## 🎯 Objective

To provide an efficient technological solution for:

* Organizing and centralizing data
* Automating operational processes
* Reducing human error
* Improving the experience of professionals and donors

---

## ⚙️ Functionalities

The system has multiple modules, all using CRUD operations:

### 📅 Scheduling

* Creating donation appointments
* Viewing appointment list
* Updating information
* Removing records

### 🙋 Volunteers

* Volunteer registration
* Search by ID
* Data update
* Record deletion

### 🧑‍⚕️ Patients

* Patient registration Patients
* Complete listing
* Information update
* Data removal

### 👨‍⚕️ Doctors

* Doctor registration
* Search by ID
* Data update
* Record deletion

### 🏥 Healthcare Volunteers

* Specific registration for healthcare volunteers
* Complete management via CRUD

### 👩‍⚕️ Nurses

* Nurse registration and management
* Complete CRUD operations

* Doctor API

* Nurse API

Each API follows the REST standard with CRUD operations.
